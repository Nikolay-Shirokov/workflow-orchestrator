# Задача 9: Исправление передачи переменных в промпт Gemini

## Статус: ✅ РЕШЕНО

## Проблема

При выполнении workflow переменная `${user_need}` не подставлялась корректно в промпт для Gemini CLI. Модель получала текст "(missing user need)" вместо реального содержимого.

### Симптомы

1. В файле `questions.md` появлялся текст: "Я бизнес-аналитик. Пользователь описал свою потребность: (missing user need)."
2. В session state переменная `user_need` содержала данные с HTML-комментариями
3. Gemini не мог извлечь полезную информацию из-за служебных инструкций в комментариях

## Анализ

### Механизм подстановки переменных

1. **Template Engine** (`src/core/template-engine.ts`):
   - Метод `render()` заменяет `${variable}` на значения из контекста
   - Поддерживает вложенные переменные через несколько проходов
   - Использует `context.variables` для получения значений

2. **Step Executor** (`src/core/step-executor.ts`):
   - Метод `createTemplateContext()` создает контекст с `variables: context.state.context`
   - Метод `preparePrompt()` рендерит шаблон промпта с подстановкой переменных
   - Переменные берутся из `context.state.context`

3. **User Input Handler** (`src/core/user-input-handler.ts`):
   - Метод `parseMarkdown()` парсит пользовательский ввод
   - Возвращает либо структурированный объект, либо plain text
   - **ПРОБЛЕМА**: HTML-комментарии из шаблона попадали в результат

### Корневая причина

HTML-комментарии `<!-- ... -->` из файлов-шаблонов (инструкции для пользователя) попадали в контекст и передавались модели. Gemini видел:

```
Ты - бизнес-аналитик. Пользователь описал свою потребность:

---
# Описание потребности

<!--
📝 Инструкции:
1. Заполните разделы ниже...
-->

# Опишите вашу потребность

Давай спроектируем решение...
---
```

Модель не могла понять, где находится реальный контент пользователя из-за служебных комментариев.

## Решение

### Реализованное исправление

**1. Удаление HTML-комментариев**

Добавлен метод `removeHtmlComments()` в `UserInputHandler`, который удаляет HTML-комментарии перед парсингом:

```typescript
/**
 * Удаление HTML-комментариев из текста
 * Используется для очистки пользовательского ввода от служебных инструкций
 */
private removeHtmlComments(text: string): string {
  // Удаляем HTML-комментарии вида <!-- ... -->
  // Используем флаг 's' для поддержки многострочных комментариев
  return text.replace(/<!--[\s\S]*?-->/g, '').trim();
}
```

**2. Удаление служебных заголовков**

Добавлен метод `removeTopLevelHeaders()` для удаления заголовков первого уровня из шаблонов:

```typescript
/**
 * Удаление заголовков первого уровня из markdown
 * Используется для очистки от служебных заголовков шаблона
 */
private removeTopLevelHeaders(text: string): string {
  const lines = text.split('\n');
  const result: string[] = [];
  
  for (const line of lines) {
    // Пропускаем заголовки первого уровня (# Заголовок)
    if (/^#\s+.+/.test(line.trim())) {
      continue;
    }
    result.push(line);
  }
  
  return result.join('\n').trim();
}
```

Метод `parseMarkdown()` теперь очищает ввод в два этапа:

```typescript
private parseMarkdown(input: string): Record<string, string> | string {
  // 1. Удаляем HTML-комментарии
  let cleanedInput = this.removeHtmlComments(input);
  
  // 2. Удаляем заголовки первого уровня
  cleanedInput = this.removeTopLevelHeaders(cleanedInput);
  
  // ... остальная логика парсинга
}
```

### Результат

Теперь в контекст попадает только чистый текст пользователя:

**Было (232 символа):**
```
# Описание потребности



# Опишите вашу потребность

Давай спроектируем решение которое позволит делать снимок области экрана, распознавать текст в нем. Текст может содержать как русские так и английские буквы, цифры и спецсимволы.
```

**Стало (178 символов):**
```
Давай спроектируем решение которое позволит делать снимок области экрана, распознавать текст в нем. Текст может содержать как русские так и английские буквы, цифры и спецсимволы.
```

Gemini получает максимально компактный и релевантный промпт:

```
Ты - бизнес-аналитик. Пользователь описал свою потребность:

---
Давай спроектируем решение которое позволит делать снимок области экрана, распознавать текст в нем...
---

Твоя задача: задать 3-5 ключевых вопросов...
```
