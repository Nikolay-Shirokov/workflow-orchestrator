Все значимые изменения в проекте будут документированы в этом файле.

## [Unreleased]

### Fixed
- 🐛 Исправлена проблема с кодировкой UTF-8 при сохранении артефактов на Windows
  - Добавлено явное указание кодировки UTF-8 для всех операций чтения/записи файлов
  - Файлы теперь корректно сохраняются с русским текстом, эмодзи и многоязычным контентом
  - Добавлены тесты для проверки корректности работы с UTF-8

### Added
- 📚 Добавлена документация по поддержке UTF-8 (`docs/UTF8_ENCODING.md`)
- ✅ Добавлены тесты для проверки корректности работы с различными кодировками

### Планируется
- Веб-интерфейс для управления процессами
- Поддержка распределенного выполнения
- Интеграция с CI/CD системами
- Визуализация графа зависимостей
