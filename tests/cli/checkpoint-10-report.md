## Проверка обновления на месте

### ✅ Механизм обновления
- Использует `clearScreen()` для очистки экрана
- Перерисовывает все секции при каждом обновлении
- Курсор скрыт во время отображения
- Курсор показывается после завершения

### ✅ Обработка событий
- `onWorkflowStart()` - инициализация отображения
- `onStepStart()` - обновление текущего шага
- `onStepComplete()` - обновление статуса и истории
- `onStepError()` - отображение ошибки
- `onWorkflowComplete()` - итоговая информация

### ✅ Обработка изменения размера терминала
- Подписка на событие `resize`
- Автоматическая перерисовка при изменении размера
- Проверка минимальной ширины (60 символов)
