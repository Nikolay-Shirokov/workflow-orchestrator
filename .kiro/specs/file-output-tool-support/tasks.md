# План реализации: Поддержка инструмента записи файлов для адаптеров

## Обзор

Данный план описывает задачи для реализации универсального механизма поддержки инструмента `write_file` для CLI-адаптеров. Механизм позволит моделям записывать большие тексты напрямую в файлы, избегая проблем с обрезанием вывода при чтении из stdout.

## Задачи

- [ ] 1. Расширение типов для поддержки outputFile
  - Добавить поле `outputFile?: string` в интерфейс `AdapterRequest` в `src/core/types.ts`
  - Добавить поля `outputFile?: string` и `resultSource?: 'file' | 'stdout'` в `metadata` интерфейса `AdapterResponse`
  - _Requirements: 2.4, 5.4_

- [ ] 2. Реализация общих методов в BaseCLIAdapter
  - [ ] 2.1 Реализовать метод `extractOutputPath(prompt: string): string | undefined`
    - Извлекает путь к выходному файлу из промпта используя регулярное выражение
    - Поддерживает паттерны: "file path: <путь>" и "to file path: <путь>"
    - _Requirements: 3.2_

  - [ ] 2.2 Реализовать метод `appendFileWriteInstruction(prompt: string, outputPath: string): string`
    - Добавляет инструкцию записи в файл в конец промпта
    - Использует формат: "CRITICAL: If write_file tool is available, use it to save your response to file path: <путь>..."
    - _Requirements: 2.1, 2.2, 2.3_

  - [ ] 2.3 Реализовать метод `readResultFromFile(outputPath: string, stdout: string, waitTime?: number): Promise<{content: string; source: 'file' | 'stdout'}>`
    - Ожидает указанное время (по умолчанию 1000мс) для записи файла
    - Пытается прочитать файл, при ошибке использует stdout
    - Логирует предупреждения при проблемах с файлом
    - Возвращает контент и источник ('file' или 'stdout')
    - _Requirements: 1.4, 1.5, 5.1, 5.2, 5.3, 7.2_
