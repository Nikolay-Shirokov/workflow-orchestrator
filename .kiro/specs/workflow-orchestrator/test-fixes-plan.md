## Категории проблем

### 1. Dual-Design Integration Tests (6 тестов) - ПРИОРИТЕТ ВЫСОКИЙ
**Файл**: `tests/integration/dual-design-workflow.test.ts`

#### Проблема 1.1: Шаг 1.5 выполняется вместо пропуска
- **Тест**: "должен выполнить все основные шаги dual-design процесса"
- **Ожидается**: Шаг 1.5 (веб-исследование) должен быть пропущен когда MCP недоступен
- **Фактически**: Шаг 1.5 выполняется
- **Причина**: Условие `mcp_tools.web_search_available` не работает корректно
- **Решение**: Исправить логику условного выполнения в workflow-engine

#### Проблема 1.2: User input steps не реализованы
- **Тест**: "должен пропускать шаг 1.5 когда MCP недоступен"
- **Ошибка**: `WorkflowError: Шаги ввода пользователя еще не реализованы`
- **Причина**: Метод `executeUserInputStep` выбрасывает исключение
- **Решение**: Реализовать базовую поддержку user input или пометить тесты как skip

#### Проблема 1.3: Циклические зависимости при возобновлении
- **Тест**: "должен возобновлять выполнение после ввода пользователя"
- **Ошибка**: `Невозможно построить порядок выполнения: обнаружены циклические зависимости`
- **Причина**: Логика resume создает неверный граф зависимостей
- **Решение**: Исправить метод `resume` в workflow-engine

#### Проблема 1.4: Директория сессии не создается
- **Тест**: "должен организовывать артефакты в директории сессии"
- **Ожидается**: `sessionDirExists = true`
- **Фактически**: `sessionDirExists = false`
- **Причина**: Артефакты сохраняются в `session_current` вместо уникальной директории
- **Решение**: Исправить логику создания директорий в artifact-manager

#### Проблема 1.5: Ошибки в параллельных шагах не обрабатываются
- **Тест**: "должен корректно обрабатывать ошибку в одном из параллельных шагов"
- **Ожидается**: `rejects.toThrow()`
- **Фактически**: Promise resolved (успешно завершился)
- **Причина**: Mock адаптер не выбрасывает ошибку как ожидается
- **Решение**: Исправить mock адаптер или тест

#### Проблема 1.6: Copilot адаптер не вызывается
- **Тест**: "должен отслеживать количество вызовов каждого адаптера"
- **Ожидается**: `copilotCalls > 0`
- **Фактически**: `copilotCalls = 0`
- **Причина**: Конфигурация ролей не работает корректно
- **Решение**: Проверить и исправить role-manager
