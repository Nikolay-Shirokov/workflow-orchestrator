# План реализации: OpenAI-совместимый HTTP API адаптер

## Обзор

Этот план описывает пошаговую реализацию адаптера для работы с OpenAI-совместимыми HTTP API. Адаптер будет поддерживать как обычные, так и streaming запросы, работать с различными локальными и облачными сервисами, и полностью интегрироваться с существующей системой адаптеров.
