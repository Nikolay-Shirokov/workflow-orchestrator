# Руководство по миграции промптов

## Обзор

Этот документ содержит рекомендации по обновлению промптов для использования улучшенной системы передачи контекста.

## Ключевые изменения

### 1. Двойная передача контекста

Теперь каждый артефакт доступен двумя способами:

```yaml
outputs:
  architect_questions: "${artifacts_dir}/step2_architect_questions.md"
```

Создает в контексте:
- `architect_questions` - содержимое артефакта (строка)
- `architect_questions_file` - путь к файлу (строка)

### 2. Три способа использования контекста

#### Способ 1: Прямое содержимое (РЕКОМЕНДУЕТСЯ)

```markdown
## Вопросы архитектора

${architect_questions}
```

**Преимущества:**
- ✅ Самый быстрый (нет чтения файла)
- ✅ Простой синтаксис
- ✅ Меньше операций I/O
- ✅ Содержимое уже в памяти

**Используйте когда:**
- Артефакт < 100KB
- Нужна максимальная производительность
- Содержимое не меняется между шагами

#### Способ 2: Загрузка из файла с тегами

```markdown
## Вопросы архитектора

${artifact:${architect_questions_file}:architect_questions}
```

**Результат:**
```markdown
## Вопросы архитектора

<architect_questions>
# Вопросы архитектора

1. Какие технологии использовать?
2. Какая архитектура предпочтительна?
...
</architect_questions>
```

**Преимущества:**
- ✅ Четкие границы контекста для AI
- ✅ Помогает модели различать вложенные данные
- ✅ Полезно для сложных промптов с множеством вложений

**Используйте когда:**
- Промпт содержит много вложенных данных
- Нужно помочь модели различать части промпта
- Важна структурированность для AI

#### Способ 3: Загрузка из файла без тегов

```markdown
## Вопросы архитектора

${artifact:${architect_questions_file}}
```

**Преимущества:**
- ✅ Гарантия актуальности данных
- ✅ Файл может быть обновлен внешним процессом
- ✅ Явная загрузка из файла

**Используйте когда:**
- Файл может быть изменен между шагами
- Нужна гарантия свежести данных
- Артефакт > 100KB (экономия памяти)

## Рекомендации по выбору способа

### Используйте прямое содержимое (${variable}), если:
- ✅ Артефакт < 100KB
- ✅ Нужна максимальная производительность
- ✅ Промпт простой, без множества вложений
- ✅ Содержимое не меняется между шагами

### Используйте загрузку с тегами (${artifact:${variable_file}:tag}), если:
- ✅ Промпт содержит много вложенных данных
- ✅ Важна структурированность для AI
- ✅ Нужно помочь модели различать части промпта
- ✅ Артефакт может быть большим

### Используйте загрузку без тегов (${artifact:${variable_file}}), если:
- ✅ Файл может быть изменен внешним процессом
- ✅ Нужна гарантия актуальности данных
- ✅ Артефакт > 100KB (экономия памяти)
- ✅ Промпт простой, теги не нужны

## Производительность

### Сравнение производительности

| Способ | Время | Операции I/O | Память |
|--------|-------|--------------|--------|
| Прямое содержимое | ~1мс | 0 | Высокая |
| Загрузка (с кэшем) | ~5мс | 0 | Средняя |
| Загрузка (без кэша) | ~50мс | 1 | Низкая |

### Рекомендации

1. **Для большинства случаев**: Используйте прямое содержимое
2. **Для больших артефактов (>100KB)**: Используйте загрузку из файла
3. **Для сложных промптов**: Добавляйте теги для структурированности
4. **Для часто используемых артефактов**: Полагайтесь на кэш (работает автоматически)

## Обратная совместимость

**Важно:** Все существующие промпты продолжат работать без изменений!

Старый синтаксис:
```markdown
${artifact:${copilot_questions_file}}
```

Будет работать корректно после исправления. Миграция на новый синтаксис опциональна и рекомендуется только для оптимизации производительности.

## Вопросы и ответы

**Q: Нужно ли обновлять существующие workflow?**
A: Нет, они продолжат работать. Обновление рекомендуется для оптимизации.

**Q: Когда использовать теги?**
A: Когда промпт содержит много вложенных данных и важна структурированность для AI.

**Q: Как выбрать между содержимым и путем?**
A: Для артефактов < 100KB используйте содержимое, для больших - путь.

**Q: Работает ли кэширование автоматически?**
A: Да, кэш работает автоматически для всех загрузок из файлов.

**Q: Можно ли смешивать разные способы?**
A: Да, можно использовать разные способы для разных артефактов в одном промпте.
