# Спецификация: Исправление UTF-8 кодировки в Artifact Manager

## Статус
✅ **ЗАВЕРШЕНО** (2026-01-10)

## Контекст

Пользователь работает на Windows и столкнулся с проблемой некорректного сохранения артефактов с русским текстом. При сохранении файлов через `ArtifactManager` кириллица отображалась как кракозябры.

### Исходная проблема
- Файлы артефактов сохранялись с неправильной кодировкой на Windows
- Русский текст не читался корректно
- Пример проблемного файла: `artifacts/session_2026-01-10T1645/step1_user_request.md`

### Причина
В коде использовался неправильный формат передачи параметра кодировки в Node.js File System API:
```typescript
// ❌ Неправильно (передача строки вместо объекта опций)
await fs.writeFile(path, content, 'utf-8');

// ✅ Правильно (передача объекта опций)
await fs.writeFile(path, content, { encoding: 'utf-8' });
```

## Риски и ограничения

### Риск: Консоль Windows
**Описание:** Команда `type` в cmd.exe может некорректно отображать UTF-8 файлы  
**Митигация:** Это не проблема самих файлов - они сохранены корректно. Документация содержит инструкции по просмотру файлов.

### Ограничение: Старые редакторы
**Описание:** Очень старые программы могут не поддерживать UTF-8  
**Решение:** Использовать современные редакторы (VS Code, Notepad++, и т.д.)
