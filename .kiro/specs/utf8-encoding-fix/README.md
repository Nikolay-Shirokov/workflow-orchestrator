## 🎯 Краткое описание проблемы

Пользователь на Windows столкнулся с проблемой некорректного сохранения артефактов с русским текстом. Кириллица отображалась как кракозябры.

**Причина:** Неправильный формат передачи параметра кодировки в Node.js File System API

**Решение:** Замена строкового формата `'utf-8'` на объектный `{ encoding: 'utf-8' }`

### Использование

```typescript
import { createArtifactManager } from './dist/core/artifact-manager.js';

const artifactManager = createArtifactManager({
  baseDir: './artifacts',
});

// Сохранение русского текста
const russianContent = `# Заголовок
Это текст на русском языке.`;

const path = await artifactManager.save(
  'session-id',
  'step-id',
  'document.md',
  russianContent
);

// Загрузка
const content = await artifactManager.load(path);
console.log(content); // Корректно отображает русский текст
```
