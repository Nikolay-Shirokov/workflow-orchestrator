## Технические детали

### Причина проблемы
Node.js File System API принимает параметр encoding двумя способами:
1. Как объект опций: `{ encoding: 'utf-8' }` ✅
2. Как строку: `'utf-8'` ❌ (не работает на Windows)

На Windows второй вариант игнорируется, что приводит к использованию системной кодировки по умолчанию.

### Решение
Унификация всех вызовов на объектный формат `{ encoding: 'utf-8' }`, который работает корректно на всех платформах.

### Влияние на систему
- **API:** Без изменений (обратная совместимость)
- **Производительность:** Без изменений
- **Безопасность:** Без изменений
- **Функциональность:** Улучшена (корректная работа с UTF-8)
