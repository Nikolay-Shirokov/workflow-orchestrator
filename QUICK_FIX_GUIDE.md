# Быстрое руководство: Исправление файлового ввода

## Что было исправлено?

Исправлены три критические проблемы, из-за которых не работал файловый ввод пользователя:

1. ❌ Редактор не открывался
2. ❌ Интерактивное меню не показывалось  
3. ❌ Роль не имела разрешений на создание файлов

## Как использовать исправленную версию?

### Шаг 1: Пересоберите проект

```bash
npm run build
```

### Шаг 2: Запустите workflow

```bash
node dist/cli/cli.js run examples/business-requirements-simple.yaml
```

### Шаг 3: Заполните файл

1. Откроется Notepad (или другой редактор) с файлом-шаблоном
2. Заполните поля в файле:
   - Что вы хотите создать?
   - Для кого это?
   - Какие ограничения?
3. Сохраните файл (Ctrl+S)
4. Закройте редактор или вернитесь в терминал

### Шаг 4: Выберите действие

В терминале появится интерактивное меню:

```
======================================================================
📝 Файл готов к заполнению
======================================================================

Файл: user_need_input.md

Выберите действие (используйте стрелочки ↑↓ и Enter):

  ▶ ● Продолжить
    ○ Отложить

======================================================================
```

**Управление:**
- ↑↓ - выбор опции
- Enter - подтверждение
- Ctrl+C - отмена (с сохранением состояния)

### Шаг 5: Продолжите workflow

После выбора "Продолжить":
1. Система прочитает ваш файл
2. Роль `analyst` создаст вопросы для уточнения
3. Вы снова заполните файл с ответами
4. Система сгенерирует финальные бизнес-требования

## Настройка редактора

Если хотите использовать другой редактор, измените в `examples/business-requirements-simple.yaml`:

```yaml
settings:
  default_editor:
    command: "notepad"  # Измените на ваш редактор
    args: []            # Аргументы командной строки
    wait: false         # true = ждать закрытия редактора
```

**Примеры редакторов:**

| Редактор | Команда | Платформа |
|----------|---------|-----------|
| Notepad | `notepad` | Windows |
| VS Code | `code` | Все |
| Notepad++ | `notepad++` | Windows |
| Sublime Text | `subl` | Все |
| Vim | `vim` | Linux/Mac |
| Nano | `nano` | Linux/Mac |

## Устранение проблем

### Проблема: "Редактор не найден"

**Решение:** Система автоматически пробует альтернативные редакторы. Если ни один не найден, вы увидите путь к файлу для ручного открытия.

### Проблема: "Роль не имеет разрешения"

**Решение:** Убедитесь, что в определении роли есть разрешения:

```yaml
roles:
  analyst:
    adapter: "gemini-cli"
    role_definition: "..."
    permissions:
      - read
      - edit: "*.md"
```

### Проблема: "Процесс завис"

**Решение:** 
1. Нажмите Ctrl+C для безопасной остановки
2. Состояние будет сохранено
3. Возобновите позже командой `resume`
