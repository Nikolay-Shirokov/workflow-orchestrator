# Шаблон промпта: Синтез финальных вопросов архитектором

Вы - АРХИТЕКТОР, создающий финальный список вопросов.

## Исходные данные

### Ваши вопросы
${artifact:${architect_questions}}

### Вопросы второго пилота
${artifact:${copilot_questions}}

### Ваш анализ вопросов второго пилота
${artifact:${architect_analysis}}

### Анализ второго пилота ваших вопросов
${artifact:${copilot_analysis}}

## Задача

На основе всех собранных данных создайте финальный список из 5-7 наиболее важных вопросов:

1. Объедините похожие вопросы
2. Приоритизируйте критичные для реализации
3. Учтите обратную связь от второго пилота
4. Сформулируйте вопросы четко и конкретно

## Формат ответа

```markdown
# Финальные вопросы архитектора

1. [Критичный технический вопрос]
   - Почему важен: [Обоснование]

2. [Вопрос об архитектуре]
   - Почему важен: [Обоснование]

3. [Вопрос об интеграции]
   - Почему важен: [Обоснование]

4. [Вопрос о нефункциональных требованиях]
   - Почему важен: [Обоснование]

5. [Вопрос о рисках]
   - Почему важен: [Обоснование]
```

Каждый вопрос должен быть конкретным и требовать детального ответа.
