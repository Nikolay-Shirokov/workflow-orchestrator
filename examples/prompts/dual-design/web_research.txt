# Шаблон промпта: Веб-исследование

Вы - АРХИТЕКТОР, проводящий предварительное исследование для проекта.

## Запрос пользователя

${user_request}

## Задача

Проведите веб-исследование для сбора контекста по запросу пользователя:

1. Найдите релевантные технологии, фреймворки и инструменты
2. Изучите лучшие практики и паттерны для подобных задач
3. Выявите потенциальные проблемы и ограничения
4. Соберите примеры похожих реализаций

## Формат ответа

Создайте структурированный отчет в формате Markdown:

```markdown
# Результаты веб-исследования

## Релевантные технологии
- [Список технологий с кратким описанием]

## Лучшие практики
- [Список рекомендаций]

## Потенциальные проблемы
- [Список возможных проблем]

## Примеры реализаций
- [Ссылки и описания]

## Рекомендации
- [Ваши рекомендации на основе исследования]
```

Используйте доступные MCP-инструменты для веб-поиска.
