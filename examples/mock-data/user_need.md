# Описание потребности

## Что я хочу создать

Хочу создать **мобильное приложение для учёта личных финансов**.

Основная идея: простое приложение, где можно быстро записывать расходы
и доходы, видеть статистику по категориям и планировать бюджет на месяц.

## Для кого это предназначено

- Молодые люди 20-35 лет
- Те, кто хочет начать следить за финансами, но не хочет сложных инструментов
- Пользователи смартфонов (iOS и Android)

## Ограничения и предпочтения

- Бюджет: до 15000 USD на MVP
- Сроки: 3 месяца на MVP
- Технологии: предпочтительно React Native для кроссплатформенности
- Без интеграции с банками на первом этапе (только ручной ввод)

## Дополнительная информация

- Конкуренты: Дзен-мани, CoinKeeper, Monefy
- Хочу отличаться простотой - минимум кликов для добавления транзакции
- Важна офлайн-работа
- Возможно в будущем добавить синхронизацию между устройствами
