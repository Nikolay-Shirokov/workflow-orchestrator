# Ответы на вопросы по требованиям

## Функциональность

### Основные функции для MVP
1. Быстрое добавление расхода/дохода (1-2 клика)
2. Категории расходов (еда, транспорт, развлечения, etc.)
3. Просмотр баланса и истории
4. Простая статистика по категориям за месяц
5. Установка месячного бюджета

### Способ добавления транзакций
- Главный экран с большой кнопкой "+"
- Быстрый ввод суммы на калькуляторе
- Выбор категории иконкой
- Опционально: заметка

## Пользовательский опыт

### Целевое время на добавление транзакции
- Максимум 5 секунд для типичной транзакции
- Без обязательных полей кроме суммы и категории

### Важные экраны
1. Главный экран - баланс + быстрое добавление
2. История транзакций
3. Статистика (круговая диаграмма по категориям)
4. Настройки (категории, бюджет)

## Технические аспекты

### Платформы
- iOS (приоритет) и Android
- React Native для кроссплатформенности

### Хранение данных
- Локально на устройстве (SQLite/Realm)
- Без облачной синхронизации в MVP
- Экспорт в CSV для бэкапа

### Офлайн-работа
- 100% функциональность офлайн
- Это критически важно

## Бизнес-модель

### Монетизация в MVP
- Бесплатное приложение
- Без рекламы
- Возможно premium в будущем

### Метрики успеха
- 1000 установок за первый месяц
- DAU/MAU > 30%
- Средняя оценка в сторах > 4.0

## Дизайн

### Стиль
- Минималистичный
- Светлая тема (темная в будущем)
- Яркие цвета для категорий

### Референсы
- Простота как у Monefy
- Статистика как у CoinKeeper
