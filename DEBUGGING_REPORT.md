## Обнаруженные и исправленные проблемы

### Проблема 1: Кодировка UTF-8 в PowerShell скриптах ❌ → ✅

**Описание:**  
При выполнении script-шагов с использованием PowerShell, русский текст сохранялся с неправильной кодировкой (кракозябры).

**Причина:**  
PowerShell по умолчанию использует кодировку, отличную от UTF-8. При захвате stdout через `child.stdout.on('data')` текст декодировался неправильно.

**Решение:**  
1. Добавлена явная установка UTF-8 кодировки в PowerShell:
   ```typescript
   const utf8Script = `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8; ${script}`;
   args = ['-NoProfile', '-Command', utf8Script];
   ```

2. Добавлена явная кодировка при декодировании stdout/stderr:
   ```typescript
   child.stdout?.on('data', (data: Buffer) => {
     stdout += data.toString('utf-8');
   });
   ```

3. Добавлена поддержка UTF-8 для CMD:
   ```typescript
   args = ['/c', 'chcp 65001 >nul && ' + script];
   ```

**Файл:** `src/core/step-executor.ts`  
**Метод:** `executeScript()`

**Результат:**  
✅ Русский текст теперь корректно сохраняется в артефактах
