## Детали по провалившимся тестам

### 1. artifact-manager.property.test.ts - Property 31 (2 теста)

**Проблема**: Нестабильность на Windows из-за:
- Задержек файловой системы (файлы не успевают сохраниться за 150ms)
- Нечувствительности к регистру (`z.txt` и `Z.txt` - один файл)

**Примеры ошибок**:
```
Counterexample: ["AD0","jai","t--_B.log","Awn"]
Expected: true (файл существует)
Received: false
```

**Решение**: Требуется:
- Увеличить задержки до 300-500ms для Windows
- Добавить фильтр в генератор для исключения имен, отличающихся только регистром
- Или пометить тесты как `skip` на Windows

### 2. artifact-manager.property.test.ts - Property 33

**Проблема**: Конфликт имен файлов на Windows
```
Counterexample: ["000","0-",[["z.txt","a"],["Z.txt","S"]]]
Expected: "a"
Received: "S"
```

Файлы `z.txt` и `Z.txt` перезаписывают друг друга на Windows.

**Решение**: Добавить нормализацию имен к нижнему регистру в генераторе.
