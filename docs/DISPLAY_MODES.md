# Режимы отображения CLI

Workflow Orchestrator поддерживает два режима отображения прогресса выполнения:

## Интерактивный режим (по умолчанию)

Интерактивный режим предоставляет структурированное отображение с обновлением на месте:

- Заголовок с названием процесса и версией
- Путь к директории артефактов
- Список всех шагов с их статусами
- Детальная информация о текущем шаге
- История последних действий (последние 2-3 шага)
- Общий прогресс выполнения с прогресс-баром

### Использование

```bash
# Интерактивный режим используется по умолчанию
node dist/cli/cli.js run workflow.yaml

# Или явно (не требуется)
node dist/cli/cli.js run workflow.yaml
```

### Требования

- Терминал должен поддерживать ANSI escape codes
- Минимальная ширина терминала: 60 символов
- Интерактивный режим (не перенаправление вывода)

Если терминал не соответствует требованиям, система автоматически переключится на логовый режим.

## Логовый режим

Логовый режим выводит информацию последовательно без обновления на месте. Это традиционный режим вывода, совместимый со всеми терминалами и подходящий для:

- Перенаправления вывода в файл
- Использования в CI/CD пайплайнах
- Скриптов и автоматизации
- Терминалов без поддержки ANSI

### Использование

```bash
# Явное указание логового режима
node dist/cli/cli.js run workflow.yaml --log-mode

# Также работает с командой resume
node dist/cli/cli.js resume session_id workflow.yaml --log-mode
```

## Сравнение режимов

| Характеристика | Интерактивный | Логовый |
|----------------|---------------|---------|
| Обновление на месте | ✓ | ✗ |
| Структурированное отображение | ✓ | ✗ |
| Прогресс-бар | ✓ | ✓ |
| Цветовая индикация | ✓ | ✓ |
| Перенаправление в файл | ✗ | ✓ |
| CI/CD совместимость | ✗ | ✓ |
| Требования к терминалу | Высокие | Низкие |

## Автоматическое переключение

Система автоматически переключается на логовый режим в следующих случаях:

1. Терминал не поддерживает ANSI escape codes
2. Ширина терминала меньше 60 символов
3. Вывод перенаправлен в файл или pipe
4. Терминал не интерактивный (например, в CI/CD)

## Переменные окружения

Вы можете использовать переменные окружения для управления режимом:

```bash
# Принудительно использовать логовый режим
export WORKFLOW_LOG_MODE=1
node dist/cli/cli.js run workflow.yaml

# Отключить цвета (автоматически включает логовый режим)
export NO_COLOR=1
node dist/cli/cli.js run workflow.yaml
```

## Отладка

Для отладки проблем с отображением используйте:

```bash
# Подробный вывод с логовым режимом
node dist/cli/cli.js run workflow.yaml --log-mode --verbose

# Проверка возможностей терминала
node -e "console.log(process.stdout.isTTY, process.stdout.columns)"
```
